# Mills Concert Hall

A 4K-only concert library: 87 full shows across classic rock, grunge, jam bands, guitar heroes, jazz fusion and more.

Open `index.html` in any browser, or publish it with GitHub Pages (Settings → Pages → Deploy from branch → `main`). Every show plays inside the page or opens in YouTube for full 4K on a TV.

`catalog.json` holds the lineup if you want to edit it.
